The idea

One letter that holds the whole product

Aleem is an assistant that answers every inquiry in under 60 seconds. The mark says that in three moves. The letters of the wordmark are drawn from the same circles and pills, so the logo and the interface are one family.

  1. Start with an a

    A ring and a stem. A for Aleem.

  2. Make the bowl a chat bubble

    One corner tightens, exactly like the tail corner on ChatBubble.

  3. Add the spark

    A dot over the stem turns a into ai. It is the only gradient in the logo.

Logo versions

Pick the version for the space

Every version is an outlined SVG with its colours baked in. Use the file as it is. The descriptor lockups are for the design system itself; products use the plain logo.

Backgrounds

Each ground has its own file

Light grounds take the navy tile. Night and navy take the dark files, whose lighter tile keeps an edge. The gradient, photos and single-ink print take the one-colour files.

Space and size

Give it room, keep it legible

Clear space

Keep a quarter of the tile’s height free on every side, which is two spark diameters. Nothing enters it: no text, no edges, no other logos.

Typography

Plus Jakarta Sans, set tight and bold
