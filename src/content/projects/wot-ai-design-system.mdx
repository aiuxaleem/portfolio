## What it is

The design system for WorldOfTaxonomy, built as a running React app and not a static style guide: every component, token and colour in the documentation is the same code that uses them. It was built end to end from a Figma file through the Figma MCP server, with Claude Code as the executing agent. Strategy, brand and design decisions were mine.

## What is in it

- **Foundations:** 203 tokens in six layers (palette, neutral, semantic, typography, spacing, radius) and 44 dark-theme overrides. Cyan is the only saturated brand colour.
- **Components:** ten primitives: Button, Button Group, Input, Select, Checkbox, Radio, Card, Modal, Toast and Tooltip.
- **Documentation:** 19 pages covering foundations, each component with its props, a showcase and a playground.
- **Brand:** a globe-in-crosshair mark with lockup and favicon masters, clear space and minimum sizes.

## How AI builds with it

The playground takes a plain request, such as a sign-in form or a pricing grid, and returns an interface made only from the system's components. One manifest file feeds both sides: it is the instruction given to the model and the list of what the renderer will accept. Anything the model invents outside that list shows up as a visible "unknown tag" label instead of being drawn, event handlers are removed, and links are limited to safe addresses.

## Status

The foundation and the components are shipped. Storybook and an installable package are pending. Still ahead: a server that lets agents query the system directly, automated quality gates, and a pilot in a first product.

It is one of the design systems I built at Colaberry, with the [Colaberry Design System](/work/colaberry-design-system), the [Multi-brand token system](/work/multi-brand-token-system) and the [Freight platform design system](/work/freight-design-system).
