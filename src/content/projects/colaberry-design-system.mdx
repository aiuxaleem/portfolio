## What it is

The design system for Colaberry, the School of Data Science and Analytics. It turns the brand into something people can build with: 231 token values, 20 React components, a marketing website kit and 15 templates. The documentation site renders the same code that ships.

## What people make with it

- **Presentations:** 16:9 deck slides.
- **Web:** a program page template and a three-screen marketing website kit.
- **Social and messaging:** a social media kit for seven platforms, a WhatsApp batch kit and an Eventbrite kit.
- **Print:** brochure, one-pager, comparison sheet, proposal, case study, certificate, business card, event poster and standee.
- **Email:** a newsletter template.

Each template has a Download button that saves a full-size image, and an Edit button that copies a ready prompt for Claude.

## Who uses it

Colaberry's development team uses it for product and web work. Colleagues in sales and marketing, who are not designers, use the templates and the prompt recipe to make their own decks, pages and campaign assets.

The same approach runs five more brands from one component library: see the [Multi-brand token system](/work/multi-brand-token-system). I also built the [Freight platform design system](/work/freight-design-system) and the [WoT AI Design System](/work/wot-ai-design-system) at Colaberry.
